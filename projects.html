OmniCMS - Multi-Platform CMS Integration

Client Project

A comprehensive Python and Django-based platform that manages content across 10+ CMS and marketing platforms including HubSpot, Drupal, Shopify, Contentful, and more. Features versioned plugin system and robust error handling.

Overview

OmniCMS is a Python and Django-based platform that makes it easy to manage content across multiple CMS and marketing platforms. It uses a versioned plugin system, allowing multiple versions of the same CMS integration to work together and evolve independently.

Key Features
  • Backend: Django REST Framework handling content creation, updates, and connection tests
  • Adapter System: Protocol-based adapters with smart caching and retry logic
  • Plugin Support: Multiple authentication methods and publishing modes (draft/publish/scheduled)
  • Dynamic Forms: Auto-generated frontend forms with real-time data population
  • 10+ Integrations: HubSpot, Drupal, Shopify, Contentful, Wix, Joomla, Magento, Salesforce, WebFlow, GoHighLevel
Testing & Quality
  • 145 test files with 21K+ lines of integration tests
  • Realistic test data and type checking
  • Automated CI/CD pipelines with pre-commit hooks
  • Strict code quality rules and OpenAPI documentation
Performance & Security
  • Stateless design with no stored credentials
  • Optimized caching for fast CMS lookups
  • Secure OAuth workflows
  • Connection pooling for improved performance
Impact

OmniCMS provides a single hub to manage content across many platforms, avoiding vendor lock-in and making it fast to add new CMS platforms. Foundation for future improvements like scheduling, bulk updates, and analytics.
